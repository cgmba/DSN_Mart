# DSN Mart Sales Prediction — DSN AI Bootcamp 2026

## 1. Problem Definition

DSN Mart is a retail business operating across different store formats and locations. The objective of this challenge is to predict the total sales generated by a product at a particular store using the product and store characteristics provided in the dataset.

This notebook presents an end-to-end machine learning workflow covering:

1. Data understanding and quality assessment
2. Exploratory data analysis
3. Data preprocessing
4. Feature engineering
5. Model development
6. Cross-validation
7. Model comparison
8. Ensemble modelling
9. Prediction generation
10. Submission validation

The central objective is to build a model that generalizes well to previously unseen product-store observations while avoiding target leakage during validation.
